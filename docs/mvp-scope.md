# MVP Scope v1

## In Scope
- Register/Login with campus email domain restriction
- Create, edit, delete, deactivate listings
- Browse listings
- Search by keyword
- Filter by category and price
- Listing detail page
- Listing status management: Available / Reserved / Sold / Removed
- Basic internal messaging for each listing

## Out of Scope
- Real payment
- Delivery/logistics
- Admin moderation dashboard
- Real-time chat
- Email verification service
- Multi-image upload
- Recommendation system
- Public marketplace for external users

## Simplifications
- First version supports only campus email suffix restriction
- First version messaging is standard request/response, not WebSocket
- First version supports one image only
